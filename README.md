# Smart Student Task and Deadline Manager

A responsive browser-based task manager that helps students organize assignments, exams, projects, and personal tasks.

## Features
- Add tasks with a category, deadline, and priority.
- Mark tasks as completed or pending.
- Delete tasks.
- Search by task title or category.
- Filter tasks by status.
- Dashboard counters for total, pending, and completed tasks.
- Save tasks in browser `localStorage`, so they remain after refreshing the page.
- Responsive layout for desktop and mobile screens.

## Technologies
- HTML5: page structure and form controls.
- CSS3: responsive layout and visual styling.
- JavaScript: task logic, filtering, counters, and event handling.
- Browser localStorage: persistence between visits on the same browser.

## Run the project
1. Download or clone this repository.
2. Keep `index.html`, `style.css`, and `script.js` in the same folder.
3. Open `index.html` in a modern browser.
4. Add a task, set a deadline, and test the completion, search, filter, and delete features.

No server or package installation is required.

## Repository structure
- `index.html` — user interface.
- `style.css` — page styling and responsive design.
- `script.js` — application logic.
- `screenshots/` — report/output preview images.

## Note
Tasks are stored locally in the browser on the current device. Clearing browser site data may remove them.
